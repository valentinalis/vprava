Фінансові формули та інструменти в Excel (UKR / ENG)

Повний теоретичний довідник для розв'язування задач в Excel українською та англійською мовами.

Ануїтет ПЛТ / PMT

UKR: =ПЛТ(ставка; кпер; пс)

ENG: =PMT(rate; nper; pv)

Обчислює рівномірний щомісячний платіж за ануїтетною схемою.
• ставка / rate — місячна ставка (річна / 12).
• кпер / nper — кількість місяців.
• пс / pv — початкова сума кредиту (знак мінус - перед сумою).

Сумування СУМ / SUM

UKR: =СУМ(E5:E16)

ENG: =SUM(E5:E16)

Підраховує загальну суму всіх виплачених відсотків або платежів у стовпчику графіка.

Посилання Абсолютні посилання ($A$1)
Приклад: =$B$1 / 12 або =$C$2 * E5

Символ $ фіксує (заморожує) номер рядка та стовпця під час автозаповнення формул у таблиці вниз.

Логіка ЯКЩО / IF

UKR: =ЯКЩО(умова; істина; хибність)

ENG: =IF(logical_test; value_true; value_false)

Використовується для перевірки умов та виведення відповідного повідомлення чи обчислення.

Аналіз даних Підбір параметра (Goal Seek)
Меню: Дані → Аналіз «Що-якщо» → Підбір параметра (ENG: Data → What-If Analysis → Goal Seek)

Спеціальний інструмент Excel, який зворотним шляхом обчислює вхідне значення клітинки (наприклад, яка потрібна ставка чи сума), щоб підсумкова формула дала точно потрібний вам результат.
